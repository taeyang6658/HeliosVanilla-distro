# KKMK 서버 배포 파일

`KKMK 서버` Helios Launcher가 사용하는 Minecraft 1.20.4 Fabric 배포 저장소입니다.

- 서버 주소: `kkmk.kro.kr:25565`
- Fabric Loader: `0.19.3`
- 클라이언트 모드: 28개
- 모드 설정, JourneyMap 미니맵 설정, 서버 목록, BSL 셰이더팩 포함
- `options.txt`는 배포 대상에서 제외해 각 사용자의 음량·키·화면 설정을 보존
- JourneyMap 설정은 최초 설치 때만 내려받고 이후 사용자 변경과 지도 데이터를 보존
- 자동 접속 활성화

계정 정보, 로그, JourneyMap 과거 지도/웨이포인트, 월드와 스크린샷은 포함하지 않습니다.
