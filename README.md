# 헬리오스 바닐라 배포 파일

`헬리오스 바닐라` Helios Launcher가 사용하는 Minecraft 1.20.4 Fabric 배포 저장소입니다.

- 서버 주소: `kkmk.kro.kr:25565`
- Fabric Loader: `0.19.3`
- 클라이언트 모드: 28개
- 모드 설정, JourneyMap 미니맵 설정, `options.txt`, 서버 목록, BSL 셰이더팩 포함
- 자동 접속 활성화

계정 정보, 로그, JourneyMap 과거 지도/웨이포인트, 월드와 스크린샷은 포함하지 않습니다.
